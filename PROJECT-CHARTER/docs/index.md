# Project Charter — Auditoría SDLC de AstraLog III

Software (SDLC)** aplicada al proyecto **AstraLog – Solución Logística Centralizada**,
desarrollado por el startup académico **CoreSystems Solutions** para la empresa
**ASTRAMACO III**.
