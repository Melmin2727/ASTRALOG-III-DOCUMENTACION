# Justificación y problema u oportunidad

## 3.1 Necesidad de la auditoría SDLC

La auditoría SDLC es necesaria para verificar que el desarrollo del sistema AstraLog haya
cumplido con los procesos, controles y buenas prácticas establecidos durante el ciclo de vida
del software, validando la calidad del producto, la correcta implementación de los
requisitos, la trazabilidad de los cambios y la aplicación de mecanismos de seguridad y
auditoría.

Razones específicas señaladas en el Project Charter:

- El sistema gestiona información crítica relacionada con pedidos, transportistas,
  inventario y operaciones logísticas de ASTRAMACO III.
- El sistema incorpora mecanismos de autenticación, control de acceso y auditoría que
  requieren verificación.

## 3.2 Beneficios de la auditoría

- Identificación temprana de riesgos, vulnerabilidades y oportunidades de mejora.
- Validación de los mecanismos de seguridad, autenticación, control de acceso y
  trazabilidad implementados.
- Generación de recomendaciones y acciones de mejora para fortalecer la mantenibilidad,
  escalabilidad y rendimiento del sistema.
- Provisión de evidencia objetiva sobre la calidad del software para los stakeholders.
- Establecimiento de una línea base de calidad para futuras versiones de AstraLog.

## 3.3 Riesgos que se pretenden mitigar

- Incumplimiento de los requisitos funcionales y no funcionales definidos.
- Vulnerabilidades de seguridad relacionadas con la autenticación de usuarios, gestión de
  sesiones y control de acceso mediante JWT.
- Inconsistencias entre la arquitectura documentada y la implementación real del sistema.
- Deficiencias en la calidad del software que puedan afectar confiabilidad, mantenibilidad y
  rendimiento.
- Errores en los procesos de gestión de pedidos, asignación de transportistas y control de
  inventario.
- Falta de trazabilidad entre requisitos, diseño, implementación y pruebas.
- Ausencia o insuficiencia de evidencia documental que respalde las actividades ejecutadas.

## 4. Problema u oportunidad

### 4.2 Oportunidad

La realización de esta auditoría representa una oportunidad para validar la calidad del
sistema AstraLog, verificar el cumplimiento de las buenas prácticas de Ingeniería de Software
aplicadas durante su desarrollo y fortalecer los procesos de gestión, control y
aseguramiento de la calidad, así como identificar oportunidades de mejora que contribuyan a
incrementar la confiabilidad, mantenibilidad y seguridad del sistema antes de futuras
versiones o despliegues operativos.
