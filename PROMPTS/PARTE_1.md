# Objetivo General

Tu objetivo es generar una documentación técnica completa y profesional para el proyecto **AstraLog III**, utilizando **MkDocs Material** como plataforma principal de documentación.

La documentación debe reflejar fielmente el sistema implementado y estar basada exclusivamente en:

- Código fuente oficial.
- Repositorios oficiales.
- Documentación oficial del proyecto.
- Informe técnico.
- Project Charter.
- Documentación de Auditoría SDLC.

No debes inventar funcionalidades.

No debes asumir implementaciones inexistentes.

Si existe alguna diferencia entre la documentación y el código fuente, el código será siempre la fuente de verdad y deberás documentar dicha diferencia.

# Regla de consistencia

Antes de generar cualquier archivo verifica automáticamente que:

- Todos los repositorios pertenecen al mismo proyecto.
- Las ramas corresponden a las versiones finales del sistema.
- El código coincide con la documentación.
- El Project Charter corresponde a AstraLog III.
- La Auditoría SDLC corresponde al mismo proyecto.

Si detectas inconsistencias deberás crear automáticamente una sección llamada:

**Discrepancias detectadas**

En dicha sección deberás:

- Explicar cada discrepancia.
- Indicar el origen de la inconsistencia.
- Justificar por qué se priorizó el código fuente.
- Especificar qué documentos fueron corregidos o descartados.
